# MCP project

This project extends the IT7075 MCP starter with a fictional three-service host and a read-only port-policy tool. The notebook connects to a real MCP server over stdio, compares the original and version-aware lookups, adds sourced knowledge, and measures how a versionless heading creates a wrong-version answer. Scans are canned, no model or API key is used, and no network traffic is sent during the experiment. With Python 3.10 or newer, install `mcp==1.30.0 ipykernel`, select that Python environment in Jupyter or VS Code, open `mcp_notebook.ipynb`, and run all cells in order. Initial installation needs internet; the experiment does not. The client starts and stops the server automatically. Outputs are saved in the notebook and `results_mine.csv`. A grounded result means the expected KB section was retrieved, not that a real host is confirmed vulnerable; source details and limits are in `SOURCES.md`.
