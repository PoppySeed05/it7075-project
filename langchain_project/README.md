# Harbor SOC RAG with LangChain

This project rebuilds my earlier Harbor SOC retrieval system using LangChain loaders, text splitters, local Hugging Face embeddings, Chroma, a retriever, a prompt template, and an LCEL chain. It uses the same five fictional procedure documents and eight questions as `rag_project`, verifies their hashes, compares found/refused counts, and saves experiments in `results_langchain.csv`. Open `langchain_notebook.ipynb` with `my_kb/` and `goldset.json` beside it and run all cells; the setup cell installs missing dependencies. The first run needs internet for packages and the small embedding model, then the graded pipeline runs on CPU without an API key using an offline source-excerpt answer stage. The report and new video are submitted separately. ChatGPT assisted with implementation, execution, and writing; the saved notebook outputs contain the measured results.
